# 🧠 AstrBot 拟人化记忆核心 (Humanlike Core)

一个纯本地运行的轻量级拟人记忆插件。不依赖 Embedding 向量库，不依赖外部插件，单文件 SQLite 运行。让你的 Bot 拥有“人类脑回路”的记忆与情感。

## ✨ 核心特性
- **人类脑回路记忆**：具备漏斗过滤（情绪、自我关联、纠错强制覆盖）。
- **艾宾浩斯遗忘**：记忆随时间衰减，跌破阈值变为“模糊影子”，触发关键词才能唤醒。
- **三阶亲密度演进**：基础好感（上限50）+ 默契羁绊（上限25）+ 灵魂共鸣（上限25），靠打卡聊不出真感情，交心与和解才能突破上限。
- **心情回归机制**：情绪会随事件跳跃，但每天睡眠后会通过函数回归到基线（50附近）。
- **拟真分句输出**：清洗机器味，强制短句，自动按标点切分并延迟发送（模拟真人打字）。
- **赛博日记本**：支持每日在后台生成日记（`/diary` 查看）。

## 🚀 安装方法
在 AstrBot 的 WebUI 后台 -> 插件 -> 从 URL 安装，粘贴本仓库链接：
`https://github.com/yingyemaoz/astrbot_plugin_humanlike_core`

或直接将本文件夹放入 `data/plugins/` 目录下。

## 🎮 核心指令
- `/status`：查看当前心情与三阶亲密度面板。
- `/ping`：测试插件存活。

## ⚙️ 配置面板
支持在后台可视化调整：记忆衰减率、影子记忆阈值、单次回复最大字数、是否开启赛博日记。
